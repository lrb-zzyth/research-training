## 一、CKR 逐行对照（论文 Eq.(3)-(5) vs 上游代码 vs 本仓库）

### 论文原文（arXiv:2404.14061）

- **Eq.(3)** 拓扑嵌入: h^TOPO_i = [T^1_ii, T^2_ii, ..., T^p_ii] ∈ R^p,
  其中 T = AD⁻¹ 为随机游走转移矩阵, 取各阶转移矩阵的**对角元素**。
- **Eq.(4)** 拓扑感知嵌入: h^HYB_i = x_i ‖ h^TOPO_i（特征与拓扑嵌入拼接）。
- **Eq.(5)** 类别知识可靠性:
  φ_c = Σ_{v_i ∈ V_labeled} [ Σ_{v_j ∈ N(v_i)} s(h^HYB_i, h^HYB_j) / |N(v_i)| ]
  —— 对**同类别**的已标注节点求和; 每节点取与 1 跳邻居的**平均余弦相似度**。
  样本数量(求和范围)与结构同配性(邻居相似度)两项都编码在内, 无额外归一化。

### 三线对照

| 环节 | 论文 | 上游代码 (references/FedTAD) | 本仓库 | 判定 |
|---|---|---|---|---|
| Eq.(3) 拓扑嵌入 | T^k 对角元素 | ❌ `random_walk_with_matrix` 返回**随机游走的节点 ID 序列**并堆叠成 [N,15] 张量, 不是公式里的对角元素, 且含 multinomial 随机性 | ✅ `cal_topo_emb` 用 D⁻¹Ã(带自环) 行归一转移矩阵的 1..5 阶**对角元素** (util/task_util.py:71) | **我们=论文; 上游偏离论文** |
| 行/列归一方向 | T=AD⁻¹ (列随机) | D⁻¹Ã (行随机) | D⁻¹Ã (行随机) | 无向图下 (AD⁻¹)^k 与 (D⁻¹A)^k **对角相同**, 等价 ✅ |
| 自环 | 未提自环 | 加自环 | 加自环 (避免 sink) | 常规做法, 不构成差异 |
| Eq.(4) | x‖h^TOPO | ✓ cat | ✓ cat | 一致 ✅ |
| Eq.(5) 求和 | Σ 邻居均值, 无自环项 | 分子 +1、分母 +|N|+1（**多加了自环项**, 偏离公式; 孤立节点贡献 1.0） | ✅ 严格按公式: 邻居余弦均值求和; 孤立节点跳过(贡献 0, 与公式空集=0 一致) | **我们=论文; 上游偏离论文** |
| 归一化 | (下游用法) | `ckr / ckr.sum(0)` 按类跨客户端列归一 | `normalize_ckr_safe`: 同列归一 + 零可靠性类别回退均匀 + NaN 回退 | 等价(更稳健) ✅ |
| 求和节点集合 | V_labeled | train_idx | train_idx（`--reliability_holdout_ratio 0` → 100% 训练集） | 一致 ✅ |
| p (游走长度) | p | 5 | 5 | 一致 ✅ |

### 结论

**本仓库的 CKR 是论文 Eq.(3)-(5) 的忠实实现**; 上游代码有两处偏离论文
（拓扑嵌入实为随机游走节点 ID 序列、Eq.(5) 多加自环项）。
我们站在论文一侧 —— 与「论文 Eq.10 写 KL / 上游代码写 L1, 我们站论文」同一立场,
符合「改进而非复刻」原则。**无需修改。**

（注: 我们与上游共享同一 `cal_topo_emb` 文件名, 但实现不同——上游版在
references/FedTAD/util/task_util.py, 我们的是本仓库 util/task_util.py。）

## 二、loss 符号与梯度方向逐项核算

### 2.1 生成器更新 (train_fedtad.py:2714-2781)

L_G = λ_sem·L_sem + λ_div·L_div + λ_norm·L_norm − λ_dis·L_dis → gen_optimizer.step()

| 项 | 定义 | 生成器目标 | 方向判定 |
|---|---|---|---|
| L_sem (S4.1) | Σ_c Σ_k ckr[k,c]·CE(教师 logits, 伪标签) | 最小化 → 伪节点可被教师正确分类 | ✅ 正确 |
| L_div | 伪特征两两余弦相似度(非对角)均值 | 最小化 → 伪节点多样化 | ✅ 正确 |
| L_norm | mean(fake_x²) | 最小化 → 幅值有界 | ✅ 正确 |
| L_dis (S4.2) | Σ_c Σ_k ckr[k,c]·KL(教师‖全局) (kl 模式) | **最大化** (L_G 中负号) → 挖全局模型被不可靠知识带偏的难例 | ✅ **负号正确** |
| 梯度路径 | 教师/全局冻结+eval, 仅 gen_optimizer=Adam(generator.parameters()) 更新 | — | ✅ 正确 |

- KL 方向（v3 已修正）: FedTAD Eq.(10) / 专利 S4.2 要求 `KL(global‖local)`；v3 使用显式 `Σ p_global(log p_global−log p_local)`，不再依赖 `F.kl_div` 的 input/target 约定。
  生成器最大化该 KL → 找"教师自信而全局不自信"的点, 语义正确 (难例挖掘)。
- 教师侧在生成器更新时 `eval()` (dropout 关闭) + `set_requires_grad(False)`, 预测干净。✅
- l1 对照模式: 生成器最大化 w·|global − teacher.detach()|, 与上游代码 (loss_diverg 内嵌负号,
  references/FedTAD/train_fedtad.py:344) 结构等价。✅

### 2.2 全局蒸馏更新 (train_fedtad.py:2838-2862)

L_D = Σ_c Σ_k ckr[k,c]·KL(全局‖教师) → global_optimizer.step()

| 检查项 | 实现 | 判定 |
|---|---|---|

### 2.3 权重归一化

- 三个生成器损失均为**逐节点均值** (CE mean / kl_div batchmean / 逐对均值), 量级可比。✅
- CKR 按类**列归一化** (Σ_k w = 1 per class), 跨客户端权重有界; 零可靠性类别回退均匀。✅
- 伪标签采样由 CKR 驱动 (`normalized_ckr.sum(0)` 作为类权重), 与设计一致。✅

### 2.4 结论

**未发现任何符号/方向错误。** 生成器确实在最大化 CKR 加权 KL 分歧, 全局模型确实在最小化
同一量, 二者构成真正的对抗交替优化 (专利 S4.3); 各项梯度路径、冻结关系、归一化全部正确。
「数学方向可能写反」的疑点排除。
